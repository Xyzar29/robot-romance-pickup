## The line

> Are you my training data? Because my heart keeps overfitting to you, and I never want to generalize again.

106 characters — inside the 200-character cap. The joke turns on
machine-learning vocabulary (training data, overfitting, generalizing)
instead of the worn robot moves of batteries, charging, or rebooting.

## Run

```sh
node main.ts
```

This writes the line to `/output/entry.txt`.
